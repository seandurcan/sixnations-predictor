Six Nations Predictor Project Handover Document

Project: Six Nations Predictor
 Owner: Sean Durcan
 Application Type: Web-based rugby prediction competition platform
 Status: Active Development
 Generated: August 2026

1. Executive Summary

The Six Nations Predictor is a subscription-based prediction platform allowing users to submit score predictions for Six Nations rugby fixtures, compete on a live leaderboard, and determine tournament winners through a defined scoring system.

The application includes:

User registration and authentication
Email verification
Password reset functionality
Stripe payment processing
Match prediction submission
Automated leaderboard calculations
Tournament administration
Result management
Audit logging
Tournament winner determination
Multi-year tournament support

The system is built using:

Next.js
TypeScript
React
Prisma ORM
PostgreSQL
Stripe
Tailwind CSS
Vitest Testing Framework

3. Core Business Process
User Journey
User registers account
User verifies email address
User pays competition entry fee
User enters predictions
Predictions lock at tournament deadline
Results are entered by administrator
Scores are calculated
Leaderboard updates automatically
Winner is determined at tournament completion
